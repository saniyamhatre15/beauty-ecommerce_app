# beauty-ecommerce_app

LuxeGlow – Beauty E-Commerce app

Developed an interactive and responsive beauty e-commerce application using React.js, JavaScript, HTML, Expo and Tailwind CSS to provide a seamless online shopping experience. Designed and implemented product listing pages for makeup, skincare, haircare, bath and body, and fragrance categories. Integrated product browsing, add-to-cart functionality, a dummy checkout process, and order history to simulate an end-to-end e-commerce workflow. Developed an admin panel to support product and order management. Utilized reusable React components, interactive JavaScript functionality, responsive UI design, and structured frontend development practices to enhance usability and maintainability. Focused on intuitive navigation, organized product presentation, and a consistent user experience across different screen sizes.

Technologies & Skills: React.js, JavaScript , HTML5, Tailwind CSS, Responsive Web Design, Component-Based Development, UI Development, E-Commerce Application Development.
